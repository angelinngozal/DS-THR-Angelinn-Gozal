Program ini mengurutkan peminjam kunci berdasarkan priority, lalu menampilkan nama dan nomor kunci.

Cara Kerja

Input:
• Daftar key
• Nama + key yang dipinjam
• Priority
Data peminjam disimpan dalam list
Program mengurutkan berdasarkan priority (kecil → besar)
Output ditampilkan:
• Format: Nama | Key

Intinya
Program hanya melakukan sorting berdasarkan priority, lalu mencetak hasil sesuai urutan tersebut.
